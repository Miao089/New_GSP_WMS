# NewWMS Minimal MVP

这是基于当前蓝图收敛出的最小可运行 MVP，用于验证医疗器械 GSP WMS 的核心闭环，而不是一次性建设完整平台。

## MVP 范围

- 主数据本地化：器械主数据、客户/供应商经营范围。
- GSP 强拦截：注册证效期、供应商准入、客户经营范围。
- 入库验收：批号/效期/UDI/SN 入库，形成库存与审计日志。
- 库存质量锁定：温湿度预警后按库位锁定库存。
- 出库分配：按 FEFO 分配可用库存，并生成 AGV 搬运任务占位。
- 全程审计：关键动作写入 audit trail，避免“无痕改库存”。

## 运行

```bash
cd mvp
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
uvicorn app.main:app --reload
```

访问：

- API 文档：http://127.0.0.1:8000/docs
- 健康检查：http://127.0.0.1:8000/health

## 自动化测试

```bash
pytest
```

测试覆盖：

1. 创建器械主数据和供应商/客户资质。
2. 执行合法入库。
3. 执行出库分配并生成 AGV 任务。
4. 验证客户经营范围不匹配时被拦截。
5. 验证温度异常锁库后不能继续出库。
